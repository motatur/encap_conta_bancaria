Conta Bancaria: 
Sistema basico desenvolvido em Java para simular o gerenciamento de uma conta bancaria. O objetivo principal deste trabalho e aplicar conceitos fundamentais de Programacao Orientada a Objetos, com enfase no encapsulamento por meio de metodos de acesso e modificacao.
Funcionalidades
Permite criar uma conta definindo numero, titular e o saldo inicial.Garante o acesso seguro aos dados cadastrados por meio de metodos de leitura.Permite a atualizacao do nome do titular com validacao de seguranca.
Realiza depositos que somam ao saldo existente.Executa saques verificando se o cliente possui fundos suficientes.
Tecnologias
A aplicacao foi desenvolvida utilizando a linguagem Java, na versao 17 ou superior, aplicando as praticas do paradigma orientado a objetos.
Estrutura do Codigo
O projeto aplica o principio do encapsulamento. Os atributos da classe sao definidos como privados para que nao sofram alteracoes externas diretas. O controle e feito exclusivamente por metodos publicos.
